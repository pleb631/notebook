# 1.排序算法

## 1.1快速排序

快速排序，基于分治法，它的核心是通过选择一个基准元素，将列表分为两部分：一部分小于基准元素，另一部分大于基准元素，然后递归地对这两部分进行排序。快速排序的平均时间复杂度为 `O(nlogn)`

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr

    # 选择基准元素（这里选择最后一个元素）
    pivot = arr[-1]
    # 分区：小于基准的元素放在左侧，大于基准的元素放在右侧
    left = [x for x in arr[:-1] if x <= pivot]
    right = [x for x in arr[:-1] if x > pivot]
    # 递归排序并合并
    return quick_sort(left) + [pivot] + quick_sort(right)

# 示例
arr = [3, 6, 8, 10, 1, 2, 1]
sorted_arr = quick_sort(arr)
print(sorted_arr)  # 输出: [1, 1, 2, 3, 6, 8, 10]
```

主要有三种分区算法

### 1.1.1 挖坑法

第一步：任意选择一个元素（比如第一个元素的位置），将该值作为pivot,并将该值视为一个坑位。

第二步：定义一个right从数组最后一个元素开始即为数组右边开始向左遍历，如果找到比pivot小的值，right停下来，将right下标访问的元素赋值到上一个坑位，并将right作为新的坑位。

第三步：定义一个left从数组第一个元素开始即为数组左边开始向右遍历，如果找到比pivot大的值，left停下来，将left下标访问的元素赋值到上一个坑位，并将left作为新的坑位。

第四步：当right和left相遇时，此时它们访问的元素绝对是坑位，只需将pivot里保存的值放入坑位即可。

第五步：让他们相遇位置的左区间和右区间同样执行上述四步（即为递归）。


```c++
int Paritition1(int A[], int low, int high) {
   int pivot = A[low];
   while (low < high) {
     while (low < high && A[high] >= pivot) {
       --high;
     }
     A[low] = A[high];
     while (low < high && A[low] <= pivot) {
       ++low;
     }
     A[high] = A[low];
   }
   A[low] = pivot;
   return low;
 }

 void QuickSort(int A[], int low, int high)
 {
   if (low < high) {
     int pivot = Paritition1(A, low, high);
     QuickSort(A, low, pivot - 1);
     QuickSort(A, pivot + 1, high);
   }
 }
```

### 1.1.2 霍尔版本

第一步：选择第一个元素的位置，将该值作为pivot。

第一步：定义一个right从数组最后一个元素开始即数组的右边开始向左边遍历，如果找到比pivot小的值就停下来。

第二步：定义一个left从数组第一个元素开始即数组的左边开始向右遍历，如果找到比pivot大的值就停下来。

第三步：交换left和right的值

第四步：当left和right相遇后，将第一个元素（即为pivot的值）与它们相遇位置的值交换。

第五步：让他们相遇位置的左区间和右区间同样执行上述四步（即为递归）。


```c++
void Swap(int& a, int& b)
{   
	a ^= b;
    b ^= a;
    a ^= b;
}

int Paritition2(int A[], int low, int high) {
   int pivot = A[low];
   int originalLow = low;
   low++;
   while(low<high){
     while(low<high && A[high]>pivot){
       --high;
     }
     while(low<high && A[low]<=pivot){
       ++low;
     }
     if (low < high) {
            Swap(A[low], A[high]);
        }
   }
   if (high != originalLow) {
       Swap(A[high], A[originalLow]);
   }

   return high;
 }
```

### 1.1.3 双指针法

第一步：定义两根指针cur和next，基准值是最后一个元素

第二步：next开始往后走，如果遇到比pivot小的值，交换cur和next的值，cur++,否则next++。之后重复第二步

第三步：交换pivot和cur的值
第五步：让pivot的左区间和右区间同样执行上述四步

```c++
int Partition3(int A[], int low, int high)
{
    int pivot = A[high];  // 基准值是数组的最后一个元素
    int current = low;    // current 指针从 low 开始
    int next;


    for (next = low; next < high; ++next)
    {
        if (A[next] <= pivot) 
        {

            Swap(A[current], A[next]);
            current++; 
        }
    }

    Swap(A[current], A[high]);
    return current;
}
```
