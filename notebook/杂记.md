## 1.异或运算

异或运算具有交换律，结合律和自反性

自反性指`a^a=0`

异或运算有几个偏门使用

1.异或加密

```python
def encryption(char,key):
    return "".join([chr(ord(c)^key) for c in char])

string = "hello wolrd"
key = 193
encry = encryption(string,key)
print("加密: ",encry)
deencry = encryption(encry,key)
print("解密: ",deencry)
```



2.无中间变量的swap

```c++
// 交换a和b的值
void swap(int& a,int& b){
    a ^= b;
    b ^= a;
    a ^= b;
}
// int x = 5;
// int y = 10;
// swap(x, y);
```

3.从一组数寻找唯一不重复的元素

```c++
int findNoDuplicate(vector<int>& nums){
    int  num = nums[0];
    for(int i = 1; i < nums.size(); i++){
        num^=nums[i];
    }
    return num;
}
// vector<int> nums = {4,1,2,1,2};
```

4.异或链表

就是链表不再存储前驱指针和后继指针，而是存储一个前驱指针和后继指针的异或。这样在存储上减少一半内存



## 2.加密字段如何模糊搜索

分析：肯定不能把加密数据解密然后进行搜索

方案：可以新建一个字段，把原始字段按不同窗口尺寸进行切片，然后加密，通过一个指定的分隔符拼接在一起，然后放在新的字段中

在搜索时，把关键词进行加密然后和这个新字段进行匹配

**注意**：用分割符是为了避免每个加密切片在匹配时不会混淆



## 3.40 亿个QQ 号，1G内存，如何去重

分析：一个qq号是4个字节，40亿个就是15个G，肯定存不下

方案：由于qq号的数字增加有规律可循，一个int32最大表示42亿个，所以使用bitmap，用一个二进制位表示一个qq号是否存在。
